# Publication review

Agent review boundary, not legal advice or a human signature:

- The new files are freshly authored under the owner's existing Apache-2.0
  authorization. Conceptual backward/forward branch scenarios and public
  instruction encodings are not imported private programs or evidence.
- Only pinned public stock RTL, public license notices and pinned public
  tooling are retrieved on hosted runners. No private/sibling checkout or
  other session-state directory is read.
- Inputs are restricted to `rvfi_nextpc/**`, this new workflow and the
  existing repository LICENSE. The root bundle, public profile and existing
  PR branches remain untouched.
- Publication admits the new program ELF/binary only (no debug symbols,
  private ELF, generated model binary, object/archive, wave or build tree).
  It preserves both observed TSV streams, all raw console bytes, typed
  statuses, generated build instructions/config exports, public source
  hashes, package notices and whitelisted dependency wheel identities.
- No full environment/credential dump is collected. Commands use public
  paths under `/tmp/rvfi-nextpc-RUN_ID`; dependency metadata is collected
  by an explicit whitelist, not by redacting original trace/console bytes.
  Public copyright notices may retain legally required upstream contact
  information; no personal owner/corporate email or local path is included.
- `archive.py` checks byte lengths/SHA256, exact file set, typed console
  closure, forbidden binaries/waves and known credential/personal-path
  patterns. This automated check complements review; it is not a universal
  privacy/secret detector or a trustworthy timestamp.
- At the initial source commit, hosted CPU/miniature results are unvalidated.
  Failed preparation/measurement attempts will be archived honestly as
  STOP. Scientific FAIL will never be relabeled pair PASS.

Final evidence identities and actual coverage must be added after the bounded
hosted attempt. No automatic merge, upstream submission, profile editing,
auth-account switching, force push, DCO or human signature is authorized.
